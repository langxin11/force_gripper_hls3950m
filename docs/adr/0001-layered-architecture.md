# ADR-0001：采用分层、可测试的控制架构

- 状态：已接受
- 日期：2026-06-10

## 背景

参考项目把 DYNAMIXEL 协议、寄存器、控制状态机和串口命令集中在单个 Arduino 程序中。更换为 HLS3950 后，如果沿用这种结构，协议调试会直接影响控制算法，也无法在无硬件环境覆盖故障路径。

## 决策

控制核心使用标准 C++17，通过抽象的 `ServoBus` 访问舵机。具体控制板和 HLS3950 协议在适配层实现。上位机通过稳定的高层协议访问控制板，并提供仿真传输后端。

## 结果

- 控制逻辑可以在电脑上快速测试。
- 更换控制板或舵机协议不要求重写夹爪状态机。
- 增加了接口设计成本，但显著降低真机调试的改动范围。
