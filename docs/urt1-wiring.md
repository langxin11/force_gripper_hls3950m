# URT-1 与 HLS3950 接线

现有驱动板已由照片确认为飞特 `URT-1`。当前推荐通过 USB-C 直接连接电脑和 HLS3950 总线。

## 接口识别

照片中可识别的接口如下：

| URT-1 标识 | 用途 | HLS3950 是否使用 |
| --- | --- | --- |
| USB-C | 电脑 USB 串口 | 使用 |
| `G / V1 / S` | TTL 单线总线接口 | 使用 |
| `G / V2 / B / A` | RS485 总线接口 | 禁止用于该 TTL 型 HLS3950 |
| `DC5V-9V` | V1 低压动力输入 | 仅用于 9V 首次测试 |
| `9V-24V` | V2 电压域输入 | 不用于 HLS3950 的 TTL 接口供电 |
| `3V3 / 5V` 开关 | 通信逻辑电平选择 | 设为 5V |

HLS3950M-C001 官方规格书确认：

- 连接器：`5264-3P`；
- 引脚 1：GND；
- 引脚 2：Vcc；
- 引脚 3：Signal/TTL；
- 工作电压：9V 至 12.6V；
- 默认波特率：1 Mbps；
- 默认 ID：1。

不要只按线色连接。必须逐项对应 URT-1 丝印 `G / V1 / S` 和舵机规格书引脚。

## 方案 A：9V 单机首次测试

该方案使用 URT-1 的 V1 动力通道，适合首次 `ping` 和只读测试。

```text
电脑 USB ─────────────── URT-1 USB-C

9V 电源 ─────────────── URT-1 DC5V-9V 端子
                          |
                          +── G  -> HLS3950 GND
                          +── V1 -> HLS3950 Vcc
                          +── S  -> HLS3950 Signal/TTL
```

要求：

- 先只接一台舵机；
- 使用带限流的 9V 电源，建议限流先设在约 1A；
- 电源正负极必须依据 URT-1 端子丝印或万用表确认，照片不能可靠判断螺钉左右极性；
- 初次只执行 `ping`、型号读取和位置读取，不发送运动或模式修改命令；
- 9V 位于 HLS3950 允许范围下限，速度和输出能力低于 12V，属于正常现象。

## 方案 B：12V 正式供电

URT-1 左侧 V1 输入标注为 `DC5V-9V`。禁止把 12V 接入 V1。正式 12V 使用时，舵机
动力线必须绕过 V1，由外部电源直接供电，URT-1 只连接地和信号。

```text
电脑 USB ───────────────────── URT-1 USB-C

URT-1 G ───────┬────────────── HLS3950 GND
               └────────────── 12V 电源负极
URT-1 S ────────────────────── HLS3950 Signal/TTL

12V 电源正极 ───────────────── HLS3950 Vcc
URT-1 V1 ────── 不连接舵机 Vcc
```

两台舵机使用同一组 `GND/Vcc/Signal` 并联总线，但 ID 必须分别设置为 1 和 2。推荐使用
`12V 6A` 或更高余量的稳压电源，并在舵机支路增加保险或电子限流。两台 HLS3950 的官方
堵转电流合计约 4.8A。

## 上电顺序

1. 断电状态下检查 `GND/Vcc/Signal` 和电源极性。
2. 把 URT-1 逻辑电平开关设为 5V。
3. 首次仅连接一台舵机，并确保舵机没有连接夹爪传动机构。
4. 接通舵机电源，确认无异常发热、异味或大电流。
5. 再连接 USB-C 到电脑，查找串口设备。
6. 先执行只读 `ping`，成功后读取当前位置、电压和温度。
7. 关闭程序、USB 和舵机电源后再改线或增加第二台舵机。

## 软件基线

官方 HLS 示例已经明确以 `URT + HLS + /dev/ttyUSB0` 为测试环境。本项目固定参考的官方
源码提交为：

```text
a203373036723e0d98c6c49b67cf09a9ee299220
```

Linux 下插入 URT-1 后可使用以下命令查找稳定设备名：

```bash
ls -l /dev/serial/by-id/
```

不要先运行运动示例。首个程序只做 ID 1、1 Mbps 的 `ping` 和只读反馈。

## 仍需实测

- URT-1 在双机 1 Mbps 条件下的通信错误率；
- 外部 12V 共地接线下的信号波形；
- 双机位置和电流反馈的持续采样频率；
- URT-1 接口保护和长期温升。
