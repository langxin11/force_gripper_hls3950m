# 实施路线图

## M0：工程骨架

- 控制核心、仿真后端、单元测试和中文文档。
- 明确协议与机械参数的待验证项。

## M1：单舵机通信

- 获取官方协议手册并记录来源和硬件版本。
- 实现帧编解码、CRC/校验、超时和单机只读测试。
- 实现低输出命令和急停。

## M2：双舵机台架

- 完成双机 ID、波特率和轮询周期配置。
- 测量总线延迟、反馈频率、峰值电流和温升。
- 完成至少一小时低负载连续运行测试。

## M3：机械样机

- 完成参数化电机座、25T 连接件和皮带轮。
- 标定方向、机械行程、传动比和安全输出上限。
- 验证断电、通信中断和机械堵转行为。

## M4：力控与集成

- 建立电流反馈、触觉反馈和实际夹持力之间的标定关系。
- 实现受限的闭环力控制和数据记录。
- 增加 ROS 适配层，不在 ROS 节点中重复控制算法。
