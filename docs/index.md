# HLS3950 力控夹爪

本项目使用飞特 HLS3950 总线舵机构建双指力控夹爪。仓库当前优先完成可验证的软件和固件边界，再根据官方协议手册、样机测量和机械设计逐步接入真机。

## 当前里程碑

- 已建立可移植的 C++ 控制核心和故障状态模型。
- 已建立 Python SDK、CLI 和无硬件仿真后端。
- 已建立固件与上位机自动测试入口。
- 待确认 HLS3950 官方寄存器、控制单位和通信时序。
- 待完成电机座、25T 皮带轮和供电接线设计。

## 不做的假设

在得到官方协议和样机测试结果前，不把 HLS3950 当作 DYNAMIXEL 兼容设备，也不假设其“恒流模式”等价于可直接使用的夹持力控制。
