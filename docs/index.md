# 基于飞特 HLS3950 的双指力控夹爪

本项目使用两台飞特 HLS3950 总线舵机构建双指力控夹爪，目标是让控制、通信和机械设计均可独立验证。当前设计以 `HLS3950M-C001` 为基准，官网商品页也写作 `HL-3950-C001`；外形尺寸为 `45.22 mm × 24.72 mm × 35 mm` 且安装、输出轴、通信和供电接口匹配的飞特舵机也可作为候选，例如 `ST-3250-C001`、`ST-3235-C001` 和 `HL-3930-C001`。

## 当前状态

- 软件：C++ 控制核心、Python SDK、CLI、仿真后端和自动测试已建立。
- 机械：HLS3950 基体、主动轮和从动轮结构的 CAD 适配已基本完成。
- 下一步：复核实物尺寸，完成打印装配，并验证 URT-1 双机通信、供电和反馈频率。

## 阅读顺序

1. [总体架构](architecture.md)与[主机通信协议](host-protocol.md)：了解软件分层、安全策略和命令格式。
2. [HLS3950 通信适配](hls3950-adaptation.md)与 [URT-1 接线](urt1-wiring.md)：进行台架测试。
3. [机械设计与装配](mechanical.md)：查看 CAD 变更、复用件和装配要求。
4. [开发与测试](development.md)：运行测试和提交前检查。

在完成官方资料核对和样机验证前，不假设 HLS3950 兼容 DYNAMIXEL，也不把恒流模式直接等同于夹持力控制。
