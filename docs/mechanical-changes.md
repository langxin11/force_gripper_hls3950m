# 机械改造清单

原夹爪围绕 ROBOTIS XL430-W250-T 设计。XL430 官方外形为
`28.5 x 46.5 x 34 mm`，HLS3950 官方外形参数为 `45.22 x 24.72 x 35 mm`，而且两者
安装孔、输出轴中心和输出接口完全不同。因此不能只扩大原电机槽完成替换。

## 必须重做

### 1. 主框架和电机座

对应原零件：`holder_base.stl`。

- 重建两侧电机容纳腔、固定耳和螺钉孔位。
- 重新确定输出轴中心高度，使驱动轮与惰轮、皮带夹持点保持共面。
- 给 HLS3950 的 15cm 出线预留弯曲半径、应力释放和左右电机布线路径。
- 电机座应做成可拆卸模块，通过统一孔阵列连接主框架，避免下一次换电机时重做整框。
- HLS3950 峰值扭矩远高于 XL430，需要加厚电机座根部和轴心附近结构；软件限流不能代替结构安全裕量。

推荐结构是“保留中央导轨框架 + 左右可更换舵机支架”，而不是继续把电机槽与整块框架打印成一体。

### 2. 驱动皮带轮和轴连接

对应原零件：`driving_pulley.stl`。

- 原皮带轮通过 XL430 输出盘的四个 M2 孔固定，不能安装到 HLS3950。
- HLS3950 使用 `25T/OD5.9mm` 花键，应新增独立的 25T 花键轮毂或采用金属舵盘。
- 推荐采用“金属 25T 舵盘/轮毂 + 螺钉连接的 HTD3M 皮带轮”两件式结构，不建议让打印件直接承受花键根部的全部扭矩。
- 尽量保留原 HTD3M 齿数和节圆直径，以维持原指尖速度、夹持力换算和皮带长度。
- 皮带轮必须增加轴向止退设计，并校核螺钉剪切、轮毂开裂和偏心。

### 3. 电机紧固件

- 原项目使用 XL430 自带的 M2.5 底部螺钉，HLS3950 的安装孔和螺钉规格不同。
- BOM、装配工具、热熔螺母或金属螺母位置都要按 HLS3950 官方外形图重新定义。
- 不应使用自攻螺钉直接反复锁入承受电机反力矩的打印孔。

### 4. 动力配电安装结构

- 新增独立的 12V 大电流分配板、保险保护和连接器安装位。
- 动力线不能经过 OpenRB-150 的舵机供电口；OpenRB 只负责控制信号并与舵机电源共地。
- 配电件应固定在机器人腕部或夹爪后部，不能让线束重量和插拔力作用在舵机引线上。

### 5. 机械限位

- 在两指完全张开和闭合方向增加实体限位或缓冲块。
- 限位位置应先于滑块、皮带夹和触觉指尖发生硬碰撞。
- HLS3950 可输出更高扭矩，原项目依赖堵转检测寻找端点的做法不适合直接照搬。

## 大概率需要修改

### 皮带长度和张紧结构

如果新电机座能保持原驱动轴中心位置、皮带轮齿数和节圆直径，原 HTD3M 皮带路径可以保留。
否则需要调整皮带长度或增加可调张紧槽。设计时至少提供数毫米的张紧调节量。

### 外壳、相机和机器人接口间隙

HLS3950 的外包络和电机出线方向不同，需要重新检查与 RealSense 支架、机器人法兰、夹爪后部外壳
以及完全张开手指之间的干涉。机器人法兰转接件本身通常无需修改。

### 控制板盒

原 OpenRB-150 盒可以继续使用，但新增配电板、保险和粗电源线后，建议重做成分离式控制盒，避免动力线与总线信号线挤在同一狭小出口。

## 可直接复用的候选件

在驱动轴中心和皮带路径保持不变的前提下，以下零件原则上可以沿用：

- MGN12H 线性导轨和两个滑块；
- 指尖支架、TPU 指尖和触觉传感器安装结构；
- 惰轮、F685-2RS 轴承和 5mm 销轴；
- HTD3M 皮带，但最终长度需在 CAD 装配中复核；
- Franka/KUKA 等机器人法兰转接件；
- 相机支架，但需重新做包络干涉检查。

## CAD 参数要求

新 CAD 不应只输出 STL。至少保留以下可编辑参数：

| 参数 | 用途 |
| --- | --- |
| 舵机外包络和安装孔坐标 | 生成可更换电机座 |
| 输出轴中心相对主框架的位置 | 保持皮带共面和中心距 |
| 25T 花键/金属舵盘接口 | 驱动轮连接 |
| 驱动轮齿数和节圆直径 | 速度和夹持力换算 |
| 皮带中心距与张紧行程 | 选带和装配 |
| 指爪机械开闭极限 | 固件标定和实体限位 |

## 首版样机建议

1. 先只设计单侧可拆卸电机座和驱动轮，验证孔位、同轴度和线束空间。
2. 使用低输出做单侧皮带台架测试，确认轮毂不打滑、框架不扭转。
3. 再镜像到另一侧并装配双电机，避免一次打印完整框架后才发现轴线偏差。
4. 最终版本再合并线束固定、配电安装和机器人端干涉优化。
